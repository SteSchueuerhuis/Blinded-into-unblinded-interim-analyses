This repository contains the code used to reproduce the results from the paper 

Schüürhuis, S., Meis, J., Bokelmann, B., Kieser, M., & Herrmann, C. (2026). Blinded‐Into‐Unblinded Interim Analyses for Clinical Trials With Time‐to‐Event Endpoints. Biometrical Journal. 68(4), e70151.

Link: https://onlinelibrary.wiley.com/doi/10.1002/bimj.70151

The attached Quarto file (README.qmd) and its compiled version (README.html) contain detailed documentation of the code.
