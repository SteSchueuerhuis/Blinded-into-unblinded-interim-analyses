This repository contains the code used to reproduce the results from the paper 

Schüürhuis, S., Meis, J., Bokelmann, B., Kieser, M., & Herrmann, C. (2026). Blinded‐Into‐Unblinded Interim Analyses for Clinical Trials With Time‐to‐Event Endpoints. Biometrical Journal. 68(4), e70151.

Link: https://onlinelibrary.wiley.com/doi/10.1002/bimj.70151

The attached Quarto file (README.qmd) and its compiled version (README.html) contain detailed documentation of the code and instructions for reproducing the results. Due to their large file size, the output generated by the simulation study is not included in this repository. The corresponding folder structure is provided, and all output will be automatically saved to the respective folders when the scripts are run.
