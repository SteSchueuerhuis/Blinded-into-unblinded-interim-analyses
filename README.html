Blinded-into-unblinded interim analyses for clinical trials with time-to-event endpoints

Author

Stephen Schueuerhuis

1 Content

This files contains a short documentation of the code belonging to the submitted paper Blinded-into-unblinded interim analyses for clinical trials with time-to-event endpoints and illustrates how the results shown in the paper may be reproduced.

To begin working with the submitted code, open the R project file blinded_into_unblinded.Rproj. This ensures that all file paths are correctly set relative to the project root.

3 How to reproduce the results shown in the paper

To reproduce the results in the paper, the file master_script.R needs to be run. All output (data, designs, results, plots) will automatically be saved in the corresponding folder, mainly in the Simulation Study folder. Plots-files are named according to their appearance in the paper. Reproducibility is ensured by using seeds set in the script 1_data_simulation.R prior to the data simulation in all simulation settings.

Due to the long runtime of the whole simulation study, we provide the script repro_example.R that reprocudes the results for simulation study 1, using Pocock-boundaries. The data, designs, results and plots are saved in the folder Reproduction Example. Hence, running this script reproduces Figure 2 and Figure 3 shown in the paper.

The results presented in Section 5 (Study Example) and in the Appendix (A.1, A.5, and A.7) can be reproduced by running the corresponding R scripts, as outlined above.

4 Helper scripts

Helper functions are contained in the file 0_util.R. The file is organized into the following sections:

  • Trial simulation: Functions for simulating study entry times, survival outcomes, and censoring data for treatment and control groups under specified distributional assumptions. It also includes a function that generates a dataset at a given interim timepoint.

  • Test statistics: A wrapper function around survdiff() that extracts the normally distributed version of the log-rank test statistic from the survival package. Additionally, a function for computing the inverse normal test statistic is provided. Note, however, that in the paper’s Methods section, we use the cumulative test statistic for testing.

  • Survival parameters: Functions for translating between different parameterizations of survival models—such as event probabilities, hazards, and median survival times—under the assumption of an exponential distribution.

  • Study design: A wrapper function that constructs a study design, including its boundary set, and defines unblinding boundaries for the hybrid designs.

  • Event estimation: Functions for estimating the expected number of events at a given time, based on assumptions about survival and censoring. These functions are used to compute the boundaries of the hybrid designs, as described in Sections 2.2.4–2.2.6 of the paper.

For details, we refer to the comments in the corresponding code file.

5 Working with intermediate results

The data files are large (several GB) and therefore not included with the code. However, all result files generated by 3_evaluation.R have been uploaded to the corresponding results folder, as outlined above. Consequently, running 4_plots.R will reproduce all plots shown in the paper without the need to re-run the full data simulation.

## How to reproduce the results shown in the paper

To reproduce the results in the paper, the file `master_script.R` needs to be run. All output (data, designs, results, plots) will automatically be saved in the corresponding folder, mainly in the *Simulation Study* folder. Plots-files are named according to their appearance in the paper. Reproducibility is ensured by using seeds set in the script `1_data_simulation.R` prior to the data simulation in all simulation settings.

Due to the long runtime of the whole simulation study, we provide the script `repro_example.R` that reprocudes the results for simulation study 1, using Pocock-boundaries. The data, designs, results and plots are saved in the folder *Reproduction Example.* Hence, running this script reproduces Figure 2 and Figure 3 shown in the paper.

The results presented in Section 5 (Study Example) and in the Appendix (A.1, A.5, and A.7) can be reproduced by running the corresponding R scripts, as outlined above.

## Helper scripts

Helper functions are contained in the file `0_util.R`. The file is organized into the following sections:

-   **Trial simulation:** Functions for simulating study entry times, survival outcomes, and censoring data for treatment and control groups under specified distributional assumptions. It also includes a function that generates a dataset at a given interim timepoint.

-   **Test statistics:** A wrapper function around `survdiff()` that extracts the normally distributed version of the log-rank test statistic from the *survival* package. Additionally, a function for computing the inverse normal test statistic is provided. Note, however, that in the paper’s Methods section, we use the cumulative test statistic for testing.

-   **Survival parameters:** Functions for translating between different parameterizations of survival models—such as event probabilities, hazards, and median survival times—under the assumption of an exponential distribution.

-   **Study design:** A wrapper function that constructs a study design, including its boundary set, and defines unblinding boundaries for the hybrid designs.

-   **Event estimation:** Functions for estimating the expected number of events at a given time, based on assumptions about survival and censoring. These functions are used to compute the boundaries of the hybrid designs, as described in Sections 2.2.4–2.2.6 of the paper.

For details, we refer to the comments in the corresponding code file.
